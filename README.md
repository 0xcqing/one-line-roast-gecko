# One-Line Roast: Earbuds
A one-line roast of wireless earbuds that autoconnect to the wrong room, play someone else's ad, then go silent the moment the phone rings.
Run `node main.ts` (optionally with `MAKEFUN_OUTPUT_DIR` set) to write `entry.txt` and print its byte count.
